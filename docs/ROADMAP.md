# Roadmap

## Phase 0. 환경 구성

- Docker Compose
- PostgreSQL
- FastAPI health check
- Flutter 기본 화면

## Phase 1. 직관 MVP

- 팀/구장/경기 일정 seed
- 내 직관 일정 등록
- 내 직관 승률 통계
- 캘린더 화면

## Phase 2. 데이터 수집

- 경기 일정 수집
- 경기 결과 수집
- 경기 종료 후 박스스코어 저장
- 정정 데이터 재확인

## Phase 3. 실시간

- 경기 중 live state 저장
- 오늘 경기 API
- 앱 실시간 화면
- 푸시 알림

## Phase 4. WPA

- 이벤트 데이터 저장
- Win Expectancy 테이블
- 이벤트별 WPA
- 선수별 WPA 합산
